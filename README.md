# MedPwv Estimation App 🔬

This is a **Proof of Concept (PoC)** application developed as a testing model for future medical technology implementations. The app uses Machine Learning to estimate the **MedPwv** value based on specific input features.

## 📌 Project Overview
The goal of this project is to demonstrate the feasibility of deploying a trained Random Forest model into a cloud environment using **Streamlit** and **GitHub**. It serves as a foundation for a more robust diagnostic support tool in the healthcare sector.

## 🚀 Technologies Used
* **Python**: Core programming language.
* **Streamlit**: Web framework for the interactive interface.
* **Scikit-Learn**: Machine Learning library used for the original model.
* **Joblib**: For model serialization and loading.
* **Pandas**: Data manipulation and feature handling.

## 🛠️ How to Use
1. Enter the required values for each medical feature in the input fields.
2. Click the **"Calcular Estimativa"** (Calculate Estimation) button.
3. The model will process the data and display the estimated MedPwv value instantly.

## ⚠️ Disclaimer
**This is a testing prototype.** The results generated by this application are for demonstration and research purposes only. They should **not** be used for clinical diagnosis or medical decision-making without professional supervision and further clinical validation.
